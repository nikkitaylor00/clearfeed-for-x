Clearfeed is installed

Pin it and check that it’s active on X.

Finish setup

  1. Open Chrome’s Extensions menu (the puzzle piece). Pin Clearfeed for X to keep the purple shield in your toolbar.
  2. Open X. If X was already open, refresh that tab once. If Chrome asks for site access, allow Clearfeed to run on x.com.
  3. Click the shield. Look for Active on X and make sure Ad blocking is on. The count rises as Clearfeed finds and hides promoted posts.
