Clearfeed for X - Install in Chrome on macOS

1. Copy the "Clearfeed Extension" folder from this disk image into
   your Home folder. In Finder, choose Go > Home, or press Command-Shift-H.

2. In Google Chrome, enter chrome://extensions in the address bar.
   Turn on Developer mode, click Load unpacked, and select the copy of
   "Clearfeed Extension" in your Home folder.

3. Pin Clearfeed from Chrome's Extensions menu, then open or refresh x.com.
   The toolbar menu should say "Active on X."

Updating an existing installation
Copy the new files into the folder Chrome already loads. Click Reload
on Clearfeed's card in chrome://extensions, then refresh X. Using the
same folder keeps your settings and all-time count.
