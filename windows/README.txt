Clearfeed for X - Windows setup

Requires Google Chrome 123 or newer. You can install it without
administrator access.

1. In File Explorer, right-click the downloaded ZIP and choose Extract All.
   Move the extracted "Clearfeed Extension" folder somewhere you will keep
   it, such as your user folder or Documents.

2. In Chrome's address bar, enter chrome://extensions. Turn on Developer
   mode and click Load unpacked. Select the "Clearfeed Extension" folder
   that contains manifest.json.

3. Open Chrome's Extensions menu and pin Clearfeed for X. Open or refresh
   x.com, then click Clearfeed's icon to check that it is active.

To update, copy the new extension files into the folder that Chrome
already loads, then click Reload on Clearfeed's card at chrome://extensions.
Refresh X. Using the same folder keeps your settings and all-time count.
